# QMT 只读行情监控（Phase 1）

本项目只读取 QMT/xtquant 行情，不连接账户、不下单、不读取交易密码。

## Windows 快速开始

1. 启动并登录 QMT，确保已开通 xtquant 行情接口。
2. 在安装了 xtquant 的 Python 环境中运行：
   `python monitor.py --check`（只检查接口）
3. 下载日线历史数据（首次运行）：
   `python monitor.py --download`
4. 输出一次信号：
   `python monitor.py --once`
5. 交易日定时轮询（北京时间 09:40、10:30、13:30、14:45、15:30）：
   `python monitor.py --loop`

输出写入 `output/signals.jsonl`，每条包含股票、数据时间、最新价、趋势信号及原因。日志不含账号信息。

**注意**：xtquant 需使用 QMT 提供的环境或按券商安装说明配置。行情订阅/历史数据权限、市场时钟和数据新鲜度必须先验证；缺失、过期数据将返回 `NO_DATA`，不得生成买卖信号。交易日历和节假日过滤仍待接入，loop 仅按工作日运行，节假日请勿使用无人值守模式。

## 信号定义（研究版）
- `BREAKOUT_WATCH`: 最近一个已完成交易日收盘突破此前20日最高收盘价，成交量超过此前20日均量1.5倍。
- `UPTREND`: 最近收盘价高于20日和60日均线，且20日均线高于60日均线。
- `WEAKNESS`: 最近收盘价低于20日均线。
- `HOLD_WATCH`: 其他情况。
- `NO_DATA`: 数据不足或接口失败。

信号不是自动交易指令。当前只做日线信号，不对盘中未完成K线做突破判断。后续添加行业相对强弱、组合风险预算、公告和回测。

## 测试
`python -m unittest discover -s tests -v`

## 数据与安全
- 不导入 `xttrader`，不调用任何交易 API。
- 不存储 QMT 账号、密码、资金账号。
- 默认仅包含已确认的重点标的示例；其他持仓需要逐一核对。
